# equivalence tests. estado.py reads it to draw the map.
#
# Each line: <pattern> <part> <state>
#   - pattern: path inside DS5Control/, with * as a wildcard. The first match wins.
#   - part: mapeo, perfiles, mando, virtual, app or fuera.

# "fuera" is what was left behind on purpose; it does not count in the percentage.
#
